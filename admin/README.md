# EduCommunity Egypt — لوحة الأدمن (Admin Portal)

**تطبيق منفصل تماماً** عن تطبيق الطلاب والمدرسين، مخصّص للإدارة فقط.
مبني بـ **React 18 + Vite + JSX** + **react-router** + **Tailwind CSS**، بأسلوب **بسيط للمبتدئين**: `fetch` عادي + `useState`/`useEffect` — **بدون** react-query و**بدون** shadcn/ui.

> الفيجما نفسها بتفترض بورتال منفصل: شاشة `admin_dashboard_analytics` مكتوب عليها **"EduCommunity — Admin Portal"** بمستخدم *Super Admin*.

---

## 🤔 ليه تطبيق منفصل؟

| السبب | التفصيل |
|---|---|
| **أمان** | كود الإدارة مايتحمّلش أصلاً في متصفّح الطالب أو المدرس |
| **وضوح** | كل تطبيق ليه مستخدم واحد وواجهة واحدة — مفيش تعقيد أدوار |
| **نشر مستقل** | ممكن تنشره على دومين/سب-دومين منفصل (أو حتى داخلي) |
| **خفّة** | حزم أقل بكتير من تطبيق الطلاب |

**باك اند واحد مشترك** (`http://localhost:5000`) بيخدم التطبيقين، والفصل بيتم بالـ role في التوكن + `authorize('admin')` على السيرفر.

## 🗺️ الصفحات

| المسار | الصفحة | بتعمل إيه |
|---|---|---|
| `/login` | تسجيل الدخول | دخول للأدمن فقط |
| `/` | لوحة التحكم | عدد الطلاب/المدرسين · المواد المنتظرة · المناوبون الآن + روابط سريعة |
| `/materials` | موافقة المواد | مراجعة مواد المدرسين → **موافقة** (تظهر للطلاب) أو **رفض** (تتحذف) |
| `/attendance` | حضور المدرسين | سجل جلسات الدخول/الخروج + إجمالي ساعات كل مدرس + **تقييم بالنجوم** |
| `/shifts` | شيفتات المناوبة | تعيين مدرس مناوب لكل مادة في وقت محدّد + شارة «مناوب الآن» |
| `/users` | المستخدمون | عرض وحذف الطلاب والمدرسين |

## 🔑 المهام الإدارية الأساسية

### 1) موافقة المواد (نظام الصلاحيات)
- **الأدمن** يرفع مواد **الوزارة** → معتمدة فوراً للطلاب (`source=ministry`).
- **المدرس** يرفع شرح/فيديو → `status=pending` ومايظهرش للطلاب.
- الأدمن يراجع من `/materials` ويوافق → المادة تظهر للطلاب فوراً.

### 2) حضور المدرسين والتقييم
- أول ما المدرس يعمل **login** بيتفتح سجل حضور تلقائياً في الباك.
- الأدمن يشوف إجمالي ساعات كل مدرس، والتقييم بالنجوم بيتحسب من الساعات (كل ساعة ≈ نجمة، بحد أقصى 5).

### 3) شيفتات المناوبة
- الأدمن يعيّن لكل مادة مدرس مناوب في وقت محدّد.
- الطالب في تطبيقه بيشوف «المدرس المناوب الآن» ويقدر يسأله أي وقت.

## 🔌 الربط بالباك اند

كل النداءات في **[src/api.js](src/api.js)**. التوكن بيتخزّن في `localStorage` باسم **`admin_token`** (مختلف عن تطبيق الطلاب عشان مايتلخبطوش لو اتفتحوا على نفس المتصفّح).

المسارات المستخدمة: `/auth/login` · `/admin/stats` · `/admin/users` · `/materials/pending` · `/materials/:id/approve` · `/attendance` · `/shifts`.
